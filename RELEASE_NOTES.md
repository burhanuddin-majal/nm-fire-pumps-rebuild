## Versioning
- Versions use semantic-style `MAJOR.MINOR.PATCH` numbers.
- Each newly recorded commit increments the patch number.
- Each entry gets a randomly generated serial number.
- **Commit No.** is the full Git commit SHA, linking the release note to the exact source change.
